# Sample and Reference Spreadsheets

This directory contains reference and sample spreadsheet files used for inspection and testing of B2B upload formats.

- `B2B_SuccessOrdersReport.xlsx`: Sample B2B upload export containing `Orders` and `Boxes` sheets with reference order records.
- `consignments_upload.xlsx`: Sample multi-sheet consignment and pieces logistics file.
- `sample-consignment-upload.xlsx`: Minimal test format for consignment, pieces, and invoices.

For the official application template used for exporting extracted invoice data, see `templates/B2B_bulk_upload_template.xlsx`.
